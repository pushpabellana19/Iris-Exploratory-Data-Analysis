# Iris-Exploratory-Data-Analysis
Project Overview 
This project performs Exploratory Data Analysis(EDA) on the Iris dataset using Python.

Tools Used:
-Python
-Pandas
-Matplotlib
-Seaborn

Visualizations:

1.Iris Species Count

2.Sepal Length Distribution

3.Petal Length by Species

4.Sepal Length vs Sepal Width

5.Correltion Heatmap

Key Insights:
- Setosa generally has shorter petals.
- Petal measurements help distinguish Iris species.
- Petal length and petal width are strongly correlated.
  
 Conclusion:
EDA helps us understand patterns and relationships in the Iris dataset.
